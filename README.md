# bili-pipeline · 每天自己看一小时 B 站

三个 Python 文件，把「刷视频」变成「读笔记」：选题 → 取流 → 转写 → 抽帧 → 落成一份带时间戳的文字稿。

零框架、零第三方爬虫库，只用标准库加两个可选依赖。

## 为什么做

想每天看一小时 AI 相关的内容，但三件事很烦：找选题靠平台推荐（全是标题党）、看视频要占满注意力、看完了记不住。

这个流水线把三件事拆开：机器负责筛和转写，人只负责最后判断「这条值不值得看」。

## 三个部件

| 文件 | 干什么 |
| --- | --- |
| `bili.py` | 搜索、拉元数据、取流（免登录） |
| `dig.py` | mp4 → 文字稿 + 关键帧（ffmpeg + faster-whisper） |
| `watch.py` | 选题、去重、按时长调度，产出 Markdown 笔记 |

## 免登录取流是怎么做到的

B 站的 `x/player/playurl` 接口在 `fnval=1` 时返回的是**单条 durl（mp4）**而不是 DASH 分段，这条路径不需要登录态，带上 `User-Agent` 和 `Referer` 就能直接下：

```
https://api.bilibili.com/x/player/playurl?bvid=<BV>&cid=<CID>&qn=16&fnval=1&fourk=0
```

（`qn=16` 是 360p，够转写用。）搜索接口有风控，会随机返回 412，所以 `get_json()` 带四次退避重试。

## 用法

```bash
python bili.py search "AI Agent 实测" 8     # 搜索，打印候选
python bili.py dl BV1xx411c7mD              # 下载单个视频
python dig.py video.mp4 --frames 12         # mp4 → 文字稿 + 12 张关键帧
python watch.py --minutes 55                # 全流程，按总时长挑片
```

输出目录默认是脚本旁的 `out/`，也可以用环境变量 `BILI_OUT` 指到别处（比如你的 Obsidian 笔记库）。

## 依赖

- `ffmpeg`：`pip install imageio-ffmpeg` 就有，不用单独装
- `faster-whisper`（可选）：本地转写，没有它就只能靠官方字幕
- 中文转写建议 `--model small` 起步，第一次会下 460MB 模型

## 已知限制

- **搜索有风控**：连续请求会 412，得退避。
- **过滤靠关键词表**：`BAD` 列表能挡掉「合集/教程/速成/涨停/带货」，但会误杀真正好的教程类内容。
- **转写准度取决于模型**：`small` 对术语（模型名、产品名）容易听错，重要内容我会手动核对。
- **抽帧是均匀抽**：讲得快的段落会漏，暂时没做场景切分。

## 做这个学到的东西

不是爬虫，是**「怎么把一个模糊的愿望拆成可验收的步骤」**：一开始只会「找视频」，跑起来才发现真正的瓶颈在选题质量（平台推荐的前几名大多是软广），于是加了关键词黑名单、播放量下限、时间窗口三个筛选器，把「热门」换成「近期且有人真在看」。这一条比代码本身有用。
